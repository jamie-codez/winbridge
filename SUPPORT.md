# Getting help

## First, try this

1. Open **WinBridge → Health Check**. It tells you in plain language what's missing and how to fix it.
2. Run `winbridge doctor` in a terminal for the same checks.
3. Check the game's page on [ProtonDB](https://www.protondb.com) for known problems and settings.
   Kernel-level anti-cheat games (for example online *Call of Duty* and *EA Sports FC*) **cannot
   run on Linux**, whatever launcher you use.
4. Look at the launch log: `~/.local/share/winbridge/logs/` (newest file for your game).

## Still stuck?

- **A bug or a game that won't run:** [open an issue](https://github.com/jamie-codez/winbridge/issues/new/choose)
  and include your distribution, GPU, the log and `winbridge doctor` output.
- **A question or an idea:** use [Discussions](https://github.com/jamie-codez/winbridge/discussions).
- **A security problem:** see [SECURITY.md](SECURITY.md), not a public issue.

WinBridge is maintained by volunteers, so replies can take a few days. Being specific and kind
gets you the fastest help. See our [Code of Conduct](CODE_OF_CONDUCT.md).
