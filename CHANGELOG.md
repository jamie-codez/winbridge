# Changelog

The changelog lives on the **[Releases page](https://github.com/jamie-codez/winbridge/releases)**.
Each release has notes generated from its [Conventional Commits](https://www.conventionalcommits.org),
grouped into Features, Bug Fixes, Performance and more, with downloadable packages attached.

- **Pre-releases** (`vX.Y.Z-dev.N`) come from the `dev` branch.
- **Stable releases** (`vX.Y.Z`) come from the `prod` branch.

Versions follow [Semantic Versioning](https://semver.org). The version is taken from the git tag and is
not stored in `Cargo.toml`; see [docs/RELEASING.md](docs/RELEASING.md) for why.
